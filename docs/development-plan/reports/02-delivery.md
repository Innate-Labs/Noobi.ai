## 验证计划

- 重启后保留手动字段、锁定和历史；旧版本启动/并发覆盖被拒绝。
- 模型不能覆盖锁定字段或移除原始要求；冲突和格式错误可见，失败不覆盖旧方案。
- 导入文本作为需求数据，不执行其中指令；需求 ID 和来源持续保留。
- 已运行方案不可原地编辑；已有工程在规划后改变时要求重新确认范围。
- 实际 Electron 界面验证编辑、取消、保存、历史及错误呈现；在线模型改方案验证另列，不以测试响应代替。

## 用户验收入口

从本分支生产构建启动 Noobi（本机提供隔离验收实例，CDP 9350；未改动原运行项目）。首页输入一个游戏需求，生成方案后：

1. 点击「编辑此方案」，修改镜头、风格和范围，保存；看到新版本与字段锁定，开始按钮暂不可用。
2. 点击「校验编辑后的方案」，通过后选择制作路线；或者展开文字调整，导入 Markdown/TXT，指定要组合的路线。
3. 打开版本历史核对变化；取消未保存编辑，关闭并重启后核对已保存版本。
4. 在已有项目提出修改，应显示影响说明；规划后外部修改工程，旧方案不能直接执行。

## 边界

这是制作方案编辑器，不是场景编辑器。预算为用户约束与范围说明，不能承诺或硬性保证模型费用。语义冲突依赖真实模型分析，不能宣称所有矛盾均可机械证明；不符合协议或改动锁定字段时保留旧版本并显示失败。首期仅文本计划，截图与视频理解由后续阶段补齐。原始必需要求继续保留；若新要求与其矛盾，需用户明确调整需求，不能静默削减。
