# Noobi 平台专项：可玩版本管理与完整恢复入口

日期：2026-09-25。状态：开发者自验完成，待用户验收。

## 目标与范围

用户了解版本管理与恢复的含义后回复“开始”。本轮实现 R03 的主流程：新版失败仍可试玩旧版；恢复代码、所选方案与工程素材时保留当前工程和新上传资料。只修改 Noobi 平台，没有推进《浮岛修复师》或其他用户游戏。

工作树 `<Noobi 工作树>`，分支 `codex/stage-01-plan-selection`，基线 `58975ce5d0c8a7a12613d7ee3541bf595e0df274`。修改仍在本地，未提交或推送；保留此前专项及已有素材预览修改。当前运行的旧应用仍在制作“fps竞技场”，没有重启、停止或继续该任务。新功能需要下次启动此工作树构建后生效。

## 本轮交付

1. 右侧 Inspector 新增「版本历史与恢复」。区分交付检查通过、制作失败、工程备份和旧构建；展示方案、时间、原因及相对上一工程存档的新增/修改/删除文件数。
2. 成功交付后保存独立快照，包含工程文件、选定方案及版本、素材账本、可信图片来源记录。Godot 可玩产物来自已验证的冻结构建；保存前再次核对源码和产物，没有通过检查就不发布为成功版本。
3. 新制作失败保存失败原因，保留此前成功快照。可一键试玩最后通过检查的版本，也可试玩指定有产物的备份。历史试玩使用独立预览服务，不替换当前工程。
4. 可手动保存当前工程备份。备份标为未验收，有页面不代表游戏已通过交付检查；缺少已选方案的旧工程备份不可执行完整恢复。
5. 恢复前展示确认说明。确认后先保存当前工程，再创建独立恢复副本；原项目、新修改和后来上传的资料留在原处。副本使用历史代码、原方案和工程内素材，保留项目帧率和项目级制作配置，获得新的项目与执行标识。
6. 副本默认停止，没有自动模型调用。旧体验报告移入历史，避免显示为副本刚通过的检查；用户继续后重新验证。尚未完成的素材任务标明需要核对重试，不假装已恢复供应商任务。
7. 恢复检查所有快照文件的散列、路径与权限。连续点击只产生一个副本；同一请求跨服务重启重放仍返回原副本。文件与方案、素材账本写入完成后才发布项目目录记录，失败不显示半成品项目。
8. 旧版 Godot 构建没有完整方案和素材绑定，明确标为历史构建，仅允许产物预览，不自动升级为完整版本。

## 用户验收步骤

等当前真实制作任务结束后，关闭旧应用，再从上述工作树启动新构建：

```sh
export PATH="$PWD/.noobi-private/runtime/node_modules/.bin:$PATH"
node_modules/.bin/electron .
```

1. 打开停止或完成的验收项目，展开右侧「版本历史与恢复」，确认记录类型与方案名称可见。
2. 点击「保存当前工程备份」，看到未验收备份及文件变更数量。旧项目没有已选方案时，恢复按钮应禁用并显示没有完整方案绑定。
3. 对已有通过检查存档的项目点击「试玩最后通过检查的版本」，实际操作游戏。当前工作区有新修改时，历史试玩仍应显示旧产物。
4. 选择完整版本，点击「恢复为独立副本」。先取消一次，确认没有增加项目；再确认恢复。
5. 自动进入新的「恢复副本」，状态保持停止。检查代码、所选方案和素材；回到原项目确认后来的修改及上传资料仍在。原项目历史中应多出一份恢复前备份。
6. 检查副本的体验报告：旧报告在历史文件中，不显示为新验收结论。是否继续制作由你决定。

无需调用模型的验收方式：运行 `node_modules/.bin/electron scripts/versions-ui-smoke.mjs`，查看成功输出与上述截图。脚本使用临时独立数据，完成后清理样例。

## 已知边界

- 完整恢复指已存入快照的工程、选定方案及素材账本。排除 `.git`、`node_modules`、`.godot`、`.DS_Store`；依赖和导入缓存需按工程配置重新生成。不迁移工程外引用文件、浏览器 LocalStorage/IndexedDB 游玩进度或账号凭据。
- 单个快照限制 20,000 个文件、2 GiB，不支持符号链接。暂未实现增量存储、自动清理与空间管理；重复备份会占用更多磁盘。
- 自动失败记录保存原因与方案信息，不自动复制失败代码；失败工程仍留在原项目，需要保存时使用手动备份。
- 恢复期间常规错误会清理未发布副本。进程突然退出可能留下未注册目录或元数据，本轮未实现启动时自动清理；原项目不会被覆盖，未完成请求不会冒充成功，可核对后重新发起。
- 来源记录只在素材字节与已存散列匹配时迁移。旧记录、旧构建缺失的信息不补造。
- 历史“交付检查通过”只指当时的宿主检查；不等于用户已验收游戏质量，也不替代恢复副本的重新验证。
