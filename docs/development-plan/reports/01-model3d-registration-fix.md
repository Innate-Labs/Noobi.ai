## 原因与修复

15:20:58 的 16 次连续失败均为 `noobi_asset_register`，返回 `Visual role metadata is supported only for image assets`。模型文件已生成，Agent 为角色、敌人、道具和环境模型补登记 `role` / `subjectId` 时，被仅允许图片的校验拒绝。不能将这些登记失败解读为模型文件全部生成失败。

- 允许 image 和 model3d 登记视觉分类与稳定实体 ID，保留 ID 格式、素材类型和路径校验。
- 图集网格及多个卡牌主体仍仅适用于图片；音频不能登记视觉分类。
- 工具失败事件显示宿主返回的有界错误原因，不再仅显示“结果：失败”；不输出原始参数、成功媒体内容或完整工具响应。
