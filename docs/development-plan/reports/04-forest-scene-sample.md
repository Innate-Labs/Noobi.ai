必须覆盖主角、森林守卫、主岛地貌、树木/岩石/草丛/蕨类、石板路线、能源晶体以及样板中可见的回访平台、记录道具和滑翔装备。风车、桥和检查点可复用已验证模型，必须协调尺度与材质。参考图与模型由 Noobi 内部 Agent 生成，外部测试者不代写本轮模型。

验收标准：

1. 玩家视角下形成统一的角色、环境、光照与交互物；不存在未声明的主要占位外观。
2. 主角与守卫保留真实动作及关节结构；不以整体网格移动代替姿态动画证明。
3. 可走面、边沿、障碍与视觉一致，第一座桥按真实操作开启并可通行。
4. 区域大字和机关说明不遮挡人物；附近交互提示、目标、暂停和音量可读可用。
5. 实际操作并查看开局、移动、跳跃、转镜头、互动、过桥和偏离路线/恢复情况；固定回归只作为其中一部分。
6. 分别记录技术检查、视觉评价与用户验收，不因宿主通过就认定整款游戏完成。
