核查日期：2026-09-25。依据当前工作树代码、阶段报告及《浮岛修复师》实测。此文件是待办盘点，不是开工或验收通过记录；本轮未执行新一轮测试或修改产品代码。

## 当前《浮岛修复师》仍需完成的验收

这是平台能力的验证作品，游戏文件中的修复不能直接算作 Noobi 通用能力已经完成。

1. **内容规模**：三地区已有主线原型，仍缺足够探索、挑战组合和有意义的支路。尚无 30–45 分钟完整体验证据。
2. **模型碰撞**：独立实测构建 `85e0a4bb-7794-471e-acfd-2f8f1c95c5e6` 中，玩家可走入/穿过工坊机关柜并被遮挡；需修复实体碰撞及交互空间。
3. **全场景画面**：森林、工坊、灯塔已补多类参考模型，但地面拼色、岛屿形状、光照过亮和环境密度仍需打磨。
4. **机关差异**：已加入风向、供能、分阶段灯塔校准，需验证世界线索、反馈和组合挑战，而不是只换 UI 文案。
