# Bundled game font

Fusion Pixel Font 12px proportional, Simplified Chinese regional form, upstream 2026.08.11. The original WOFF2 bytes are unmodified. OFL-1.1 and all component licenses are included; license text line endings/trailing whitespace are normalized only. Source and hashes are pinned in manifest.json.

This is an offline fallback for readable Chinese game UI, not a requirement to give every game pixel art. Games may substitute a properly licensed font matching their approved art direction. Do not copy system fonts from the developer machine for distribution. Godot imports WOFF2 as FontFile; no system font fallback or network required.
