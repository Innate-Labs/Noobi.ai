# Noobi.ai 插件与设置中心信息架构

## 目标

将项目侧栏底部的能力入口收敛为两个稳定模块：

- **插件**：统一管理 Skills 与 MCP，负责发现、安装、配置和启用 Agent 能力。
- **设置**：统一管理 API、可观测性、开发者诊断和本机依赖。

设置中心必须展示真实状态，不用静态演示数据；所有凭据继续由 macOS 安全存储保管，依赖安装只允许产品内置白名单动作。

## 全局导航

```text
Noobi.ai
├── 首页 / 项目工作台
├── 项目列表
└── 工具入口
    ├── 插件
    │   ├── Skills
    │   │   ├── 精选推荐
    │   │   └── 已安装
    │   └── MCP Servers
    │       ├── 推荐 MCP
    │       └── 已配置
    └── 设置
        ├── API 与用量
        ├── 开发者
        └── 依赖
```

## 设置中心屏幕

### 1. API 与用量（默认）

用户任务：配置各类服务、验证连通性、判断 API 是否健康、了解 Token 消耗。

内容层级：

1. 顶部汇总：调用数、成功率、平均延迟、Token 总量。
2. Provider 槽位：主 Agent、策划、图像、视频、音频；显示配置状态和最近测速。
3. 当前 Provider 编辑：Provider、Base URL、Model、API Key、安全说明、测速与保存。
4. 最近调用：时间、服务、模型、状态、耗时、输入/输出/缓存 Token。

测速是一次显式用户动作；测速结果进入最近调用记录，但与正式 Agent 调用使用不同的 `kind` 标记。

### 2. 开发者

用户任务：在排查 Agent 行为时查看实际输入、Function Calling 和调度状态。

默认关闭。开启后展示：

- **提示词**：当前项目的用户原始提示词与 `.qwen/system.md` 实际系统提示词。
- **Function Calling**：由 AgentEvent 中 `tool_call` / `tool_result` 组成的时间线，展示工具名、摘要、结果、错误与时间；敏感内容沿用现有事件持久化脱敏。
- **调度器**：当前为单任务互斥模型，展示项目、状态、Pipeline stage、当前/最近工具、会话 ID 和队列策略说明。

没有选中项目时，保留开发者模式开关并显示明确空状态，不伪造运行数据。

### 3. 依赖

用户任务：确认本机是否具备游戏制作工具，并安全安装或更新缺失依赖。

依赖分组：

- Agent 工具链：Node.js / npx、uv / uvx。
- 游戏引擎：Godot、Unity Hub、Unity Editor。
- 制作与验证：Blender、Playwright 运行环境。

每项展示名称、用途、状态、版本、检测路径、要求和可用动作。状态使用：

- `ready`：已安装可用。
- `missing`：未检测到，可用白名单安装。
- `update-available`：可更新（仅在能可靠判断时显示）。
- `managed-externally`：需要在厂商工具中继续，例如 Unity Editor 由 Unity Hub 管理。
- `checking` / `running` / `error`：检测或安装过程状态。

安全边界：主进程按固定依赖 ID 映射到固定可执行文件与固定参数；禁止 renderer 传入命令、参数或路径；禁止 `shell: true`；安装前二次确认；完整输出回显到可复制日志。

## 关键流程

### API 配置与测速

`设置 → API 与用量 → 选择服务槽位 → 编辑 → 测试连接 → 查看延迟/状态 → 保存`

### 开发者诊断

`设置 → 开发者 → 开启开发者模式 → 选择提示词/Function Calling/调度器 → 查看当前项目快照`

### 依赖安装

`设置 → 依赖 → 刷新检测 → 选择缺失项 → 确认安装 → 查看实时状态/完成日志 → 再次检测`

### 插件启用

`插件 → Skills 或 MCP → 推荐目录 → 安装/添加草稿 → 配置 → 下一个 Agent 回合加载`

## 命名与文案

- 全局入口一律使用“插件”，弹窗标题同样为“插件”；内部保留标准术语 `Skills` 和 `MCP Servers`。
- “设置”是系统级配置；“API 与用量”取代模糊的“模型与素材服务”。
- 依赖按钮根据真实动作命名：“安装”“更新”“打开 Unity Hub”，不使用统一但含义模糊的“修复”。
- 明确说明能力生效时机：Skills/MCP 在下一次 Agent 回合加载；依赖安装完成后需重新检测。

## 可访问性与响应式

- 设置主导航使用可聚焦按钮和 `aria-current`；开发者开关具有显式文本状态。
- 状态不能只依赖颜色，必须同时展示文字与图标。
- 桌面宽度下使用 `210px + minmax(0, 1fr)`；窄窗口改为顶部横向导航，内容单列滚动。
- 提示词、Function payload 和安装日志使用可滚动等宽区域，避免撑开弹窗。

## 实现边界

本版本提供真实的本地累计用量与最近调用，不推算货币费用；不同 Provider 价格与计费口径变化快，后续可在有版本化价格表时增加费用估算。本版本也不把底层 CoreToolScheduler 内存对象直接暴露给 renderer，而是展示桌面 AgentRunner 的真实单任务调度快照和工具事件。
