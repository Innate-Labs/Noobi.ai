# Capability icon sources

The inline monochrome brand glyphs used by `CapabilityIcon.tsx` were sourced
from Simple Icons v16 and are bundled locally so the Noobi.ai capability
catalog works offline:

- Unity
- Unreal Engine
- Godot Engine
- Blender
- Three.js
- Steam

Source: <https://github.com/simple-icons/simple-icons/tree/16.0.0>

Simple Icons distributes its collection under CC0-1.0. Product names and
logos remain trademarks of their respective owners; inclusion indicates
compatibility only and does not imply endorsement.

All semantic function glyphs are provided by the existing `lucide-react`
dependency under the ISC license.
